Help

Questions, answered

The stuff people ask most. Still stuck? The Discord is the fastest way to get help.

Ask in Discord
Which Minecraft version do these work on?

Every mod here is built for 1.21.11 only. Make sure your launcher profile is Fabric on 1.21.11 — other versions won't load them.

Do I need Fabric API?

Yes. Install the Fabric loader for 1.21.11, then put Fabric API in your mods folder alongside the mods.

My game crashes on launch — what do I do?

Check you're on Fabric 1.21.11 with Fabric API installed, remove any older copies of the same mod, and remember Glazed needs Meteor Client. If it still crashes, post your crash log in the Discord.

The download didn't start.

Try the button again. If your browser says the file "can harm your device", that's a standard warning for .jar files — open your downloads list and click Keep.

How does Spawner Protect work?

It uses paid APIs to locate your spawners and alerts you when players get near them. Setup notes and support are in the Discord.

Are the mods really free?

Yes — no paywalls, no keys, no ad-gates. Just click download.
