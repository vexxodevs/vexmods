Repository settings

Need a token? Make one on GitHub — it only takes a minute:
  1. Open GitHub → New fine-grained token.
  2. Name it Vexxo admin and pick an expiry (e.g. 1 year).
  3. Repository access: Only select repositories → choose vexmods.
  4. Permissions → Repository → Contents: Read and write.
  5. Click Generate token, copy it, and paste it above.
The token is only saved in this browser. Never share it — anyone with it can edit the site.

Where downloads are stored

Where a mod's .jar file goes when you publish.

For true direct downloads — the ts.buzzheavier.com link that starts the file straight away — use the Vexxo Uploader app on your computer. That link is signed and has to be fetched from Buzzheavier each time, which a web page isn't allowed to do. The uploader also refreshes it on a schedule so it never goes stale.
